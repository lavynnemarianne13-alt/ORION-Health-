# ORION — Integrated Frontend

React + TypeScript frontend connected to the FastAPI backend in the sibling `../backend` directory.

Refer to the [main README](../README.md) for setup and development commands and [API contracts](../docs/API_CONTRACTS.md) for actual supported endpoints.

**Run `npm ci` and `npm run dev` inside this folder.** Do not distribute `node_modules`.

Ultrasound is browser-only; MediaPipe/YOLO inference is not active. No clinical decisions or diagnoses.
